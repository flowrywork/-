# Проверки MVP 0.3.0

## Автоматические

```bash
node tests/server.cjs
node tests/login.cjs
node tests/login-storage.cjs
node tests/preview.cjs
node tests/daily.cjs
node tests/browser.cjs
```

Они проверяют роли и изоляцию мастеров, обязательные фото, дедупликацию, минимальный вход, версию локального хранилища, PWA-файлы, тонны и шесть именованных фото суточного отчёта. Браузерный сценарий входит мастером, отправляет отчёт с мобильной ширины и открывает его под ИТР.

Браузерный сценарий также проверяет мобильный процесс рабочего: мастер назначает задание, рабочий начинает смену, запускает задание, завершает его с комментарием и фотографией, затем открывает результат в истории.

## Ручные перед публикацией

1. Проверить вход мастера и ИТР на телефоне.
2. Создать НСО и ТБО: каждая приёмка требует пять фото — весы с грузом, весы без груза, ТС с грузом, ТС без груза и ТТН.
3. Убедиться, что мастер видит только свои записи.
4. Подтвердить запись под ИТР и проверить запрет дальнейшего редактирования.
5. Отправить суточный отчёт с шестью отдельными фото и открыть его под ИТР.
6. Проверить отчёт за 14 дней и CSV: единицы массы — только `т`.
7. После подключения Google проверить CORS/redirect, запись в Sheets, закрытый Drive и работу с двух устройств.
8. После появления постоянного HTTPS-адреса проверить PWA и только затем создать QR-код.

Экран входа содержит только логин, пароль и кнопку «Войти».
