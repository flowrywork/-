# Сервис Экология — MVP 0.3.0

PWA для учёта приёмки отходов и суточных отчётов. В MVP две роли: мастер и ИТР.

## Быстрый запуск демо

```bash
python3 build-demo.py
```

Откройте `Service-Ecology-DEMO-0.3.0.html` в браузере. Демо работает локально и хранит данные только в браузере.

Демо-аккаунты:

- мастер: `master` / `MasterDemo123!`
- ИТР: `itr` / `ItrDemo123!`

## Разработка

```bash
python3 -m http.server 8080 --directory web
```

Откройте `http://localhost:8080`. Проверки описаны в `CHECKS.md`.

## Подключение Google

Backend находится в `apps-script/`. Создайте проект Google Apps Script, добавьте файлы `.gs`, выполните `setup()`, разверните Web App и укажите его URL в `web/config.js`. Папка Drive остаётся закрытой; фотографии выдаются только после серверной проверки сессии и роли.

Реальное развёртывание требует аккаунта владельца и пока не проверено. Не размещайте пароли, ID таблицы, ID папки или токены в репозитории.

## Ограничения MVP

- Все массы указываются в тоннах.
- Каждая приёмка НСО и ТБО требует пять фото: весы с грузом, весы без груза, ТС с грузом, ТС без груза и ТТН.
- Суточный отчёт требует ровно шесть отдельных фотографий.
- Демо-данные не синхронизируются между устройствами.
- Операторы, водители, руководитель, металл, финансы и онбординг относятся ко второй волне.
